# agua-pordia
Projeto pessoal usado para treinar os conceitos aprendidos no capitulo 1 e 2 do curso da codedex em JAVA: Introdução a java e variaveis.

Calculadora de Consumo de Água Diário
O que é: Um programa criado em Java que recebe o peso do usuário e calcula exatamente quantos litros de água ele deve beber por dia.
Tecnologias Usadas: Java (Lógica matemática, Scanner para interação de usuário, e manipulação de variáveis Double/Int).

Tudo ainda é muito novo, mas estou explorando e colocando a mão na massa para possiveis projetos futuros (talvez melhorar este mesmo projeto.)
